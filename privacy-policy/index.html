Política de Privacidad — Almacén Valentina

Almacén Valentina es una aplicación de escaneo de códigos de barras para consulta de precios de productos.

Datos que recopila la app

Esta aplicación no recopila, almacena ni comparte ningún dato personal del usuario.

Uso de la cámara

La app solicita permiso de acceso a la cámara del dispositivo únicamente para escanear códigos de barras. Las imágenes capturadas no se almacenan ni se envían a ningún servidor.

Conexión a internet

La app se conecta a un servidor propio para consultar el precio del producto escaneado usando el código de barras. No se envía ningún dato personal en estas consultas.
